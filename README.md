## 🛠️ الـ Stack
Hono + TypeScript على Cloudflare Pages (relay بلا حالة) · IndexedDB + Service Worker · Tailwind مُجمَّع محلياً · marked / highlight.js / DOMPurify / JSZip (محلية)

## 🧩 API
| Method | Path | الوصف |
|---|---|---|
| GET | `/api/meta` | المزودون والإعدادات |
| POST | `/api/models` | `{apiKey, baseUrl}` → كل نماذج الحساب |
| GET | `/api/search?q=` | بحث ويب (متعدد المحركات) |
| POST | `/api/chat` | SSE — `{messages[], instructions, web, model, os, want_title}` → `meta` · `delta` · `status{search|fetch|continuing}` · `tools` · `error` · `done` |

بروتوكول الأداة: النموذج يُخرج `<<TOOL>>{"tool":"search","query":"..."}<</TOOL>>` أو `{"tool":"fetch","url":"..."}` → الخادم ينفّذ ويعيد النتيجة (حتى 4 مرات) — لا يظهر للمستخدم.

## 📖 الاستخدام
1. افتح الموقع من الهاتف → القائمة ☰ → **المزودون و مفاتيح API** → اضغط Gemini → «احصل على مفتاح» → الصق → **اتصال**. كرّر لأي مزود آخر (Groq مجاني).
2. من أعلى الشاشة اختر النموذج — القائمة مقسّمة: Gemini / Groq / … 
3. **تعليماتي الأساسية** 🧠: اكتب مثلاً «أستخدم Android فقط واشرح بالمصري» — تُرسل مع كل رسالة.
4. اكتب طلبك. لو احتاج معلومة حديثة سيبحث بنفسه (تظهر 🔍 أثناء البحث).
